Create an animated pet with ChatGPT

Choose a character and motion, then copy the prompt into web ChatGPT. Attach reference images in that chat.

This interval only affects the prompt. Use the same interval when uploading. Eight frames at 200ms loop in 1.6 seconds.

  • Recommended: eight transparent 128×128 PNGs. Keep the same canvas and size, with room for movement.
  • Each file must be at most 1MiB and 512px per side. Resize large source images before uploading.
  • Position, rotation, and brightness changes are supported. Make the last frame join smoothly to the first.
  • pet_01.png~pet_08.pngare the filenames. PNG/ICO play in filename order. Extract ZIPs and split sprite sheets into separate PNGs.
  • Keep movement margins. Cropping and centering each frame separately removes the movement.
  • Upload up to eight frames per state. Select a state and upload only its set. The pet adds status indicators and unread counters.
  • ChatGPT may not produce correct transparency, dimensions, or downloadable files on the first try. Check the files and conversion preview.

Guidance for transparency and preserving reference images follows the official OpenAI image prompting guide.

File and animation rules
  • One GIF or 1–8 PNG/ICO images. Two images alternate.
  • Each file: at most 1MiB, width and height at most 512px.
  • GIF source: at most 120 frames; up to eight frames are sampled evenly.
  • Converted to 32×32 with transparency. A shared crop enlarges the set while keeping frame movement.
  • Stored intervals: 150–2,000ms. Very fast GIFs may play slower.
  • Eight frames use 32KiB of pixels. Windows icon costs and temporary browser conversion memory are separate.
  • The original GIF is not stored in the pet. Icon choices survive restarts.
