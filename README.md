# Codex Tray Pet

> **Windows only (x64). Requires the Codex desktop app for Windows. macOS and Linux are not supported.**

[English](README.md) · [한국어](docs/i18n/README.ko.md) · [日本語](docs/i18n/README.ja.md) · [简体中文](docs/i18n/README.zh-CN.md) · [Español](docs/i18n/README.es.md)

A small animated cat in the Windows notification area that follows your Codex desktop tasks. Open its session list to see running tasks, questions, usage-limit interruptions, and unread results without switching between chats.

Built for the **Windows Codex desktop app**. The monitored desktop process is named `ChatGPT.exe`, but belongs to the `OpenAI.Codex` package. This is the Codex app shown in the examples; the separate ChatGPT desktop app and chats on chatgpt.com are not monitored.

Written in C with the Windows API. The resident app requires no Python, Node.js, .NET, or embedded browser runtime. This is an independent project, unaffiliated with OpenAI. The default language is **English**. Choose **English, 한국어, 日本語, 简体中文, or Español** from **Language**, the first item in the pet settings menu, or the selector at the very top of browser settings. The selection is saved across restarts and applies to menus, tooltips, panel labels, dialogs, browser settings, and the character-creation prompt. Session titles and project names keep their original text. These documentation links switch README language independently of the application.

## Install

1. Download `codex-tray-pet-v0.2.1-windows-x64.zip` from [Releases](https://github.com/Max-JI64/codex-tray-pet/releases).
2. Extract it to a folder you intend to keep. Moving the folder later requires registering the startup path again.
3. Run `Install.cmd`. It registers a scheduled task for your Windows user and starts the watcher.
4. If the cat is hidden, move it out of the notification area's `^` menu.

Use `Start.cmd` for a manual launch or `Uninstall.cmd` to remove automatic startup and stop this installation. Uninstall keeps your local files and settings. The scripts refuse to replace or remove a same-named scheduled task belonging to another folder.

The install/uninstall launchers use `-ExecutionPolicy Bypass` only for their own PowerShell process so internet-downloaded, unsigned helper scripts can run. They do not change your Windows or user execution-policy settings. Organization-enforced policies can still prevent installation. When updating from another folder, run that copy's `Uninstall.cmd` first. The installer verifies that the new process stays running before reporting success.

Targets **Windows x64 and the Codex desktop app**. It does not monitor the CLI, VS Code extension, or regular ChatGPT app. Closing only the Codex window leaves detection active if Codex is still in the background. Choosing **Exit** in the Codex tray menu removes the pet icon and releases its active resources. A small watcher process stays alive to detect the next Codex launch and restore the pet.

## States and sessions

| State | Default cat |
|---|---|
| Idle | Gray |
| Working | Blue, animated |
| Completed | Green |
| Question | Yellow with a question mark |
| Error | Red with an exclamation mark |
| Stopped | Purple |
| Detection uncertain | Dark gray |
| Usage exhausted | Red flashing and shaking |
| Task running for 10+ minutes | Slow motion with an hourglass |

An unread-result badge can appear while other tasks are still running. Its default color is red and can be changed in settings. Click the cat to open the session list, then click a title to open that chat in Codex. Reading a result in Codex removes it from the unread list. Row order stays stable while the panel is open. Hover over a session to see its project name; the one-line project popup prefers the right side and falls back to the left at the screen edge.

## Custom icons and settings

Language selection is the first native menu item and the topmost browser setting. See [language settings and implementation](docs/LANGUAGES.md).

Open **Settings → Change icon** to use browser settings. Upload one GIF or up to eight PNG/ICO images. You can use one shared set or a separate set for each state.

- Each input file: at most **1MiB**, width and height at most **512px**.
- GIF input: at most **120 source frames**.
- Stored animation: at most **8 frames of 32×32 RGBA**, with intervals of **150–2,000ms**.
- Transparent margins are fitted using a shared crop across the set, preserving movement between frames. Custom icons have no bottom status bar.

Only the active state's custom frames remain resident. Eight frames contain **32KiB of pixel data**; that is not the app's total memory usage. Windows icon handles, process overhead, and temporary browser conversion memory are separate. Browser settings run on demand through the same native process, with no separate resident web server or image decoder. The page includes image requirements and a character-creation prompt for ChatGPT.

### What you can change

The session panel's **Settings** button opens the native settings menu. **Change icon...** or **Open settings in browser...** opens settings in your default browser, including Chrome if it is your default. Chrome is not bundled or kept running by the pet.

| Control | Native menu | Browser settings |
|---|---|---|
| Language | First menu item; five languages | Topmost selector and Save language |
| Return to automatic detection | Yes | Yes |
| Preview states, usage-limit motion, long-task motion, or unread counter | Yes | Yes; the preview also changes the tray |
| Unread-counter color | Charcoal, red (default), blue, green, purple, white | Same six colors, with a save button |
| Animation and color changes | Toggle | Toggle and save |
| Use your own pet artwork | Opens browser settings | Choose default cat or uploaded artwork; save the selection |
| Upload animated artwork | Opens browser settings | GIF or PNG/ICO frames; choose shared or per-state slot, set conversion interval, preview, and apply |
| Character-creation guide | Available through browser settings | Enter a character, choose motion and timing, then copy a ChatGPT prompt |
| Acknowledge local completed/error/stopped indications | Yes | Yes |
| Acknowledge usage-limit flashing | Yes | Yes |
| Hide the pet for the current Codex run | Yes | Yes |
| Stop the watcher | Yes | Yes |
| Refresh settings, return to current-icon preview, close the settings connection | Open settings again | Dedicated controls |

You can replace the cat with **your own static or animated pet images**, then switch back to the default cat. A state-specific set overrides the shared set; without either, that state uses the default cat. The browser's character and motion selections generate an artwork prompt, rather than redrawing uploaded images. Acknowledging an indication affects the pet; it does not change Codex's read state or restore exhausted account usage.

## Detection, privacy, and limitations

The app reads local session records, unread state, and project information under `CODEX_HOME` or your user profile's `.codex` folder. It does not modify Codex's files. It reads only the account identifiers needed to associate unread state from login information into memory; it does not send them elsewhere.

Browser settings bind to a temporary port on `127.0.0.1` and validate the access key, Origin, and Host. The connection closes on request, after 10 minutes without API requests, or when Codex exits.

Detection follows events such as `task_started`, `task_complete`, structured errors, and question-tool calls. It can miss changes visible only in the UI, questions written only as ordinary text, and errors absent from local records. Codex's internal file formats may change. This app does not use an official live-status API. It tracks up to 256 desktop sessions and discovers sessions from roughly the last seven days. Excluded child agents do not consume session slots; a resumed session replaces its older rollout in the same slot. Large text and image payloads pass through bounded buffers; only state metadata is retained. See [session-discovery validation](docs/DETECTION-VALIDATION.md).

The release build passed the eight included automated checks on the author's Windows machine. The public v0.1.1 ZIP was downloaded and actually installed on that PC: removal, startup registration, the running process, Codex detection, tray registration, and repeated installation passed. See [installation validation](docs/INSTALLATION-VALIDATION.md). Installation on another PC, a real Codex Exit/relaunch, and a Windows login restart were not exercised. The executable is unsigned.

## Build from source

Use 64-bit Windows [TinyCC](https://bellard.org/tcc/). The compiler is not included.

```powershell
.\scripts\Build.ps1 -TccPath 'C:\tools\tcc\tcc.exe'
.\scripts\Test.ps1
.\scripts\Package.ps1
```

Build outputs go to `build`; release ZIPs go to `dist`. The tests cover parsing, large records, state priority, questions, unread results, preview overrides, custom state icons, and local settings requests. Tests that depended on real account or project sessions were removed from the distribution source. Local sessions, credentials, diagnostic logs, and user-uploaded icons are not published.

Documentation image generation additionally requires Python and Pillow; neither is required to run the pet. See [MEDIA.md](docs/MEDIA.md).
