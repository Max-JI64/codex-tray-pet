# Codex Tray Pet

[English](../../README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

Windows에서 Codex 데스크톱 앱의 작업 상태를 시계 옆 고양이 아이콘으로 알려주는 작은 프로그램입니다. C와 Windows API로 만들었으며 .NET·Python·Node 런타임을 상주시키지 않습니다. OpenAI와 별개의 개인 프로젝트입니다.

현재 프로그램 UI는 한국어입니다. 위 링크는 문서의 번역본입니다.

## 작동 모습

사용자가 제공한 실제 Windows 트레이 화면입니다.

![실제 트레이 화면](../images/actual-tray.png)

프로그램의 실제 아이콘 그리기 코드로 만든 확대 애니메이션입니다. 32×32 아이콘을 확대했으며 실제 모양·색·배지 비율과 기본 300ms 재생 간격을 유지합니다. 배경은 첨부 화면의 회색에 맞췄고, 정적인 상태는 그대로 멈춰 있습니다.

![상태별 고양이 확대 GIF](../images/states.gif)

실제 세션 창의 Windows 그리기 코드에 예제 제목과 시간을 넣어 만든 이미지입니다.

![진행·완료·질문·오류·사용량 제한 세션 창 예시](../images/session-examples.png)

진행은 경과 시간, 미확인 완료는 파란 점, 질문은 시간과 `?`, 사용량 제한은 빨간 원 안의 `i`로 표시됩니다. 현재 일반 오류의 미확인 결과도 창에서는 파란 점으로 표시되며, 트레이 고양이가 빨간색으로 바뀝니다. 예시에도 현재 동작을 그대로 반영했습니다.

확대 GIF와 예시 창은 AI 생성이나 화면 캡처 없이 코드로 만들었습니다. [이미지 출처와 재생성 방법](../MEDIA.md)을 함께 제공합니다.

## 설치

1. [Releases](https://github.com/Max-JI64/codex-tray-pet/releases)에서 `codex-tray-pet-v0.1.0-windows-x64.zip`을 받습니다.
2. 계속 사용할 폴더에 ZIP을 풉니다. 설치 후 폴더를 이동하면 자동 실행 경로도 다시 등록해야 합니다.
3. `Install.cmd`를 실행합니다. 현재 사용자의 로그인 예약 작업에 등록하고 펫을 실행합니다.
4. 시계 옆에 보이지 않으면 숨겨진 아이콘 메뉴 `^`에서 고양이를 꺼냅니다.

자동 연결이 필요 없으면 `Start.cmd`로 직접 실행하세요. 자동 연결을 해제하려면 `Uninstall.cmd`를 실행합니다. 설치·해제는 다른 프로그램의 같은 이름 예약 작업을 덮어쓰거나 삭제하지 않습니다.

Windows x64와 Codex 데스크톱 앱을 대상으로 합니다. CLI·VS Code 확장·일반 ChatGPT 앱은 감지 대상이 아닙니다. Codex 창만 닫아 백그라운드에 남으면 계속 감지하며, Codex 트레이 메뉴의 **Exit**로 종료하면 펫 표시와 관련 자원을 해제합니다. 다시 켜면 감시 프로그램이 펫을 표시합니다. Codex 종료 후에는 다음 실행을 찾는 작은 감시 프로세스가 남습니다.

## 기능

| 상태 | 기본 고양이 표시 |
|---|---|
| 대기 | 회색 |
| 작업 | 파랑, 움직임 |
| 완료 | 초록 |
| 질문 | 노랑, 물음표 |
| 오류 | 빨강, 느낌표 |
| 중지 | 보라 |
| 감지 확인 필요 | 짙은 회색 |
| 사용량 소진 | 빨간 점멸과 흔들림 |
| 10분 이상 작업 | 느린 모션과 모래시계 |

다른 작업이 진행 중이어도 읽지 않은 완료 수를 숫자 배지로 표시합니다. 고양이를 누르면 진행 중인 세션과 읽지 않은 결과를 보여줍니다. 경과 시간·질문·사용량 경고·미확인 완료 점을 표시하고, Codex에서 결과를 확인하면 목록에서 제외합니다. 열린 목록의 순서를 유지하고 제목을 누르면 해당 Codex 세션으로 이동합니다. 프로젝트에 속한 세션은 마우스를 올려 프로젝트 이름을 확인할 수 있습니다.

**설정 → 아이콘 변경**에서 브라우저 설정을 엽니다. 기본 고양이 대신 GIF 한 개 또는 PNG·ICO 최대 8장을 등록할 수 있으며, 상태마다 별도 세트를 지정할 수도 있습니다. 각 파일은 1MiB 이하·가로세로 각각 512px 이하, GIF 원본은 최대 120프레임입니다. 저장 시 최대 8개의 32×32 RGBA 프레임으로 변환하고 간격은 150~2,000ms로 제한합니다. 한 세트의 공통 투명 여백을 줄여 그림을 크게 표시하며 프레임 사이 이동을 유지합니다. 하단 색상 바는 사용하지 않습니다.

현재 상태의 사용자 프레임만 메모리에 유지합니다. 8프레임의 픽셀 데이터는 32KiB이며 프로그램 전체 메모리·Windows 아이콘 비용·브라우저의 변환 메모리는 별도입니다. 브라우저 설정은 열 때만 같은 프로세스의 로컬 연결을 사용합니다. 별도 상주 웹 서버나 이미지 디코더가 없습니다. 설정 페이지에서 캐릭터 제작용 ChatGPT 프롬프트와 이미지 규격도 확인할 수 있습니다.

## 감지 방식과 한계

`CODEX_HOME` 또는 사용자 프로필의 `.codex` 폴더에 있는 로컬 세션 기록·읽음 정보·프로젝트 정보를 읽습니다. Codex 원본 파일을 수정하지 않습니다. 로그인 정보에서는 현재 계정의 읽음 상태를 구분하는 데 필요한 식별자만 메모리로 읽고 외부로 전송하지 않습니다. 설정은 `127.0.0.1`의 임시 포트에서만 받으며 접속 키·Origin·Host를 검사합니다. 닫기·10분 동안 API 요청 없음·Codex 종료 시 연결을 해제합니다.

`task_started`·`task_complete`, 구조화된 오류, 질문 도구 호출 등을 기준으로 상태를 추적합니다. 화면에만 남는 변화, 자연어로만 묻는 질문, 기록되지 않은 오류는 놓칠 수 있습니다. Codex 내부 파일 형식이 바뀌면 감지가 달라질 수 있으며 공식 실시간 상태 API를 사용하는 프로그램은 아닙니다. 최대 256개 세션을 추적하고 최근 약 7일의 세션을 발견합니다. 큰 본문·이미지 데이터는 고정 버퍼로 통과시켜 상태 메타데이터만 보관합니다.

최초 배포본은 개발자 Windows 환경에서 빌드·논리 검사를 통과했습니다. 다른 PC의 설치, 실제 Exit 후 재실행, 로그인 재시작은 이번 배포 준비에서 실행하지 않았습니다. 실행 파일은 코드 서명되지 않았습니다.

## 소스에서 빌드

64비트 Windows용 TinyCC가 필요합니다. 이 저장소는 컴파일러를 포함하지 않습니다. [TinyCC 공식 사이트](https://bellard.org/tcc/)에서 Windows 패키지를 준비한 뒤 PowerShell에서 실행하세요.

```powershell
.\scripts\Build.ps1 -TccPath 'C:\tools\tcc\tcc.exe'
.\scripts\Test.ps1
.\scripts\Package.ps1
```

빌드는 `build`, 배포 파일은 `dist`에 생성합니다. 테스트는 세션 파서·큰 레코드 처리·상태 우선순위·질문·미확인 결과·미리보기·상태별 사용자 아이콘·로컬 설정 요청을 검사합니다. 실사용 계정이나 프로젝트의 세션을 전제로 하는 검사는 배포 소스에서 제외했습니다. GitHub에 세션 파일·계정 정보·개인 검사 로그·사용자 아이콘을 올리지 않습니다.

문서 이미지 생성에는 Python과 Pillow가 추가로 필요하지만 펫 실행에는 필요하지 않습니다. 프로젝트 배포 라이선스는 아직 선택하지 않았으며, 공개 저장소라는 사실만으로 오픈소스 라이선스가 부여되지는 않습니다.
