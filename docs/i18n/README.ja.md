# Codex Tray Pet

> **Windows x64 専用です。Windows 版 Codex デスクトップアプリが必要です。macOS と Linux は非対応です。**

[English](../../README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md)

Windows の通知領域で Codex デスクトップアプリの作業状態を知らせる、小さな猫のプログラムです。セッション一覧から、実行中の作業、質問、使用量制限による中断、未読の結果を確認できます。

C と Windows API で実装しています。常駐アプリに Python、Node.js、.NET、組み込みブラウザーは不要です。OpenAI とは無関係の個人プロジェクトです。初期言語は**英語**です。ペット設定メニューの最初の **Language / 言語**、またはブラウザー設定の一番上で **English・한국어・日本語・简体中文・Español**を選択できます。選択は再起動後も保持し、メニュー、ツールチップ、セッションのラベル、メッセージ、ブラウザー設定、制作プロンプトに適用します。セッション名とプロジェクト名は原文を維持します。文書の言語はアプリとは別に切り替えます。

**Windows 版 Codex デスクトップアプリ向けに作成しました。** 検出するプロセス名は `ChatGPT.exe` ですが、`OpenAI.Codex` パッケージの Codex アプリです。別の ChatGPT デスクトップアプリや chatgpt.com の会話は対象ではありません。

![ホバーした行の強調色と手形カーソル](../images/session-hover.png)

GIF と例のウィンドウはコードで作成しました。AI 画像生成や新たなデスクトップ撮影は行っていません。[画像の出典と再生成](../MEDIA.md)を参照してください。

## インストール

1. [Releases](https://github.com/Max-JI64/codex-tray-pet/releases) から `codex-tray-pet-v0.2.0-windows-x64.zip` をダウンロードします。
2. 今後も使用するフォルダーに展開します。移動した場合は自動起動のパスを再登録してください。
3. `Install.cmd` を実行します。現在の Windows ユーザーのログイン時タスクを登録し、監視を開始します。
4. 猫が見えない場合は、通知領域の `^` メニューから表示させます。

手動起動には `Start.cmd`、自動起動の解除とこのインストールの停止には `Uninstall.cmd` を使います。アンインストール後もファイルと設定は残ります。別のフォルダーを指す同名のタスクは上書き・削除しません。

インストール・削除の起動ファイルは、ダウンロードした未署名スクリプトを実行するため、その PowerShell プロセスだけに `-ExecutionPolicy Bypass` を適用します。Windows 全体やユーザーの実行ポリシー設定は変更しません。組織が強制するポリシーは引き続き適用されます。別のフォルダーへ更新する前に、旧版の `Uninstall.cmd` を実行してください。インストーラーは新しいプロセスが動作し続けていることを確認してから成功を表示します。

対象は Windows x64 と Codex デスクトップアプリです。CLI、VS Code 拡張機能、通常の ChatGPT アプリは対象外です。Codex がバックグラウンドに残る場合、ウィンドウを閉じても監視を続けます。Codex のトレイメニューで **Exit** を選ぶと猫の表示と使用中のリソースを解放します。次の Codex 起動を検出するため、小さな監視プロセスは残ります。

## 状態とセッション

| 状態 | 標準の猫 |
|---|---|
| 待機 | 灰色 |
| 作業中 | 青、アニメーション |
| 完了 | 緑 |
| 質問 | 黄、疑問符 |
| エラー | 赤、感嘆符 |
| 停止 | 紫 |
| 検出の確認が必要 | 濃い灰色 |
| 使用量を消費済み | 赤く点滅し、揺れる |
| 10 分以上の作業 | ゆっくりした動きと砂時計 |

他の作業中でも未読結果の件数をバッジで表示します。初期色は赤で、設定から変更できます。猫をクリックすると一覧を開き、タイトルをクリックすると Codex の該当チャットへ移動します。Codex で結果を読むと未読一覧から消えます。一覧を開いている間は行の順番を維持します。セッションにマウスを合わせるとプロジェクト名を一行で表示します。右側を優先し、画面端では左側に表示します。

## アイコンと設定

**Settings → Change icon**（設定 → アイコン変更）からブラウザー設定を開きます。GIF 一つ、または PNG/ICO を最大 8 枚登録できます。全状態に共通のセット、または状態ごとのセットを使えます。

- 入力は各ファイル最大 1MiB、縦横それぞれ最大 512px。
- GIF の元フレームは最大 120。
- 保存する形式は最大 8 フレームの 32×32 RGBA。間隔は 150～2,000ms。
- 全フレーム共通の透明余白を調整し、フレーム間の移動を維持します。カスタムアイコンに下部の状態バーは付きません。

現在の状態のフレームだけを常駐させます。8 フレームの画素データは 32KiB ですが、これはアプリ全体の使用メモリーではありません。プロセス、Windows のアイコン、ブラウザー変換時の一時メモリーは別です。設定は必要時だけ同じネイティブプロセスで動き、別の常駐サーバーや画像デコーダーはありません。ChatGPT 用のキャラクター作成プロンプトと画像仕様も掲載しています。

### 変更できる設定

セッション画面の **설정** ボタンから標準設定メニューを開きます。**아이콘 변경...** または **브라우저에서 설정 열기...** は既定ブラウザーで設定を開きます。Chrome を既定にしていれば Chrome で開きます。Chrome は同梱・常駐させません。

| 機能 | 標準メニュー | ブラウザー設定 |
|---|---|---|
| 言語 | メニューの一番上、5言語 | 最上部の選択と保存 |
| 自動検出へ戻る | 対応 | 対応 |
| 状態・使用量制限・長時間作業・未読件数のプレビュー | 対応 | 対応、実際のトレイ表示も変更 |
| 件数バッジの色 | チャコール、赤（初期値）、青、緑、紫、白 | 同じ 6 色を選んで保存 |
| 動き・色の変化 | オン／オフ | オン／オフと保存 |
| 自作の猫画像を使う | ブラウザー設定を開く | 標準猫／登録画像を選んで保存 |
| アニメーション画像の登録 | ブラウザー設定を開く | GIF または PNG/ICO、共通／状態別の枠、変換間隔、プレビュー、適用 |
| キャラクター制作ガイド | ブラウザーで提供 | キャラクター、動き、間隔を指定し ChatGPT プロンプトをコピー |
| 完了・エラー・停止の表示を確認 | 対応 | 対応 |
| 使用量制限の点滅を確認 | 対応 | 対応 |
| 今回の Codex 起動中だけ非表示 | 対応 | 対応 |
| 監視プログラムの終了 | 対応 | 対応 |
| 更新・現在のアイコン表示・設定接続の終了 | 設定を開き直す | 専用ボタン |

**自分の静止画や動くキャラクター画像を登録**でき、標準の猫にも戻せます。状態別セットが共通セットに優先し、どちらもなければ標準の猫を使います。制作ガイドの動き指定は画像作成用のプロンプトを生成するもので、登録済みの画像を描き直す機能ではありません。表示の確認は猫の通知だけに適用され、Codex の既読状態やアカウント使用量は変更しません。

## 検出、プライバシー、制約

`CODEX_HOME` またはユーザープロファイルの `.codex` にあるローカル記録、未読状態、プロジェクト情報を読みます。Codex のファイルは変更しません。ログイン情報からは未読状態の対応付けに必要なアカウント識別子だけをメモリーに読み、外部へ送信しません。

ブラウザー設定は `127.0.0.1` の一時ポートに限定し、アクセスキー、Origin、Host を検査します。終了要求、API リクエストなしで 10 分経過、または Codex 終了時に接続を閉じます。

`task_started`、`task_complete`、構造化されたエラー、質問ツール呼び出しなどを追跡します。UI のみに見える変化、通常の文章だけの質問、記録されないエラーは見逃すことがあります。内部ファイル形式の変更にも影響されます。公式のリアルタイム状態 API は使用していません。最大 256 セッションを追跡し、おおむね直近 7 日分を検出します。大きな本文・画像データは固定バッファーで通過させ、状態メタデータのみ保持します。

リリースビルドは作者の Windows 環境で 8 項目の自動検査に合格しました。公開 v0.1.1 ZIP をダウンロードしてこの PC に実際にインストールし、削除、自動起動登録、プロセス動作、Codex 検出、トレイ登録、重複しない再インストールを確認しました。[インストール検証結果](../INSTALLATION-VALIDATION.md)を参照してください。別 PC のインストール、実際の Codex Exit と再起動、Windows 再ログインは未検証です。実行ファイルは未署名です。

## ソースからのビルド

Windows 64 ビット用の [TinyCC](https://bellard.org/tcc/) が必要です。コンパイラーは含まれていません。

```powershell
.\scripts\Build.ps1 -TccPath 'C:\tools\tcc\tcc.exe'
.\scripts\Test.ps1
.\scripts\Package.ps1
```

ビルドは `build`、配布 ZIP は `dist` に出力します。パーサー、大きなレコード、状態の優先順位、質問、未読結果、プレビュー、状態別アイコン、ローカル設定要求を検査します。実際のアカウントやプロジェクトに依存する検査は配布ソースから除外しています。個人セッション、認証情報、診断ログ、ユーザーのアイコンは公開しません。

文書の画像生成には Python と Pillow が必要ですが、猫の実行には不要です。[MEDIA.md](../MEDIA.md) を参照してください。
